## 0.9.3 — November 5, 2026
- The plugin no longer runs PowerShell or sh: region, language, time zone and time format come from built-in system facilities.
- New `/limits clock 12|24|auto` command to choose 12 or 24 hours manually.

## 0.9.2 — November 5, 2026
- Technical changes for the Claude plugin directory requirements; nothing changes for users.
- The README describes in detail which programs the plugin runs and why.
